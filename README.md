# 🚀 ChatNova

ChatNova is a free anonymous random chat platform where users can instantly connect with strangers worldwide without signup.

## ✨ Features

- 💬 Anonymous Chat
- 🌍 Random Stranger Matching
- ⚡ Instant Connection
- 🔒 No Signup Required
- 📱 Mobile Friendly
- 🚀 Fast & Secure
- 🌐 SEO Optimized

---

## 🛠 Tech Stack

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- Socket.IO
- Node.js
- Vercel
